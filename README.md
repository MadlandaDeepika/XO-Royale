# XO-Royale

A browser-based Tic-Tac-Toe game featuring an AI opponent powered by the Minimax algorithm.

## 🎮 Features

- Player vs AI gameplay
- Minimax-based AI decision making
- Win, lose, and draw detection
- Restart game option
- Responsive and interactive interface

## 🛠️ Technologies Used

- HTML
- CSS
- JavaScript
- Minimax Algorithm

## 🌐 Live Demo

Play the game directly in your browser through GitHub Pages.

## 📌 Project Overview

XO-Royale is a mini web-based game project created to explore game logic, decision-making algorithms, and interactive web development.
